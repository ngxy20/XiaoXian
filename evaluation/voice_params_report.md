# 语音拟人化 A/B 测试报告

- 样本：`data/nlp.jsonl` + 8 条场景补充样例，共 **18** 条（含 gold intent/emotions）
- 评估对象：`core/voice_persona.py` + `assets/voice_emotion_params.json`

## 策略定义

- **策略 A（Baseline，现状）**：所有句子用同一句固定风格描述（`用温柔、可爱、像动漫人物，语速中快，亲切自然`），无情绪标签、语速恒定、不读人设。
- **策略 B（实验，拟人化）**：场景识别 → 关键词/模型/场景先验/上下文/人设五路加权打分 → 多情绪标签 → 混合成风格指令与语速倍率，并注入人设语气、共情规则与输出约束。

## 指标对比

| 指标 | 策略 A | 策略 B | 变化 |
|---|---|---|---|
| 情绪命中率（Jaccard，与 gold） | 0.0% | 22.2% | +22.2pp |
| 多情绪标签覆盖率 | 0.0% | 38.9% | +38.9pp |
| 故事场景召回率（gold=story，共 5 条） | 0.0% | 100.0% | +100.0pp |
| 人设语气注入率 | 0.0% | 100.0% | +100.0pp |

| 语速区分度（标准差） | 0.000 | 0.077 | +0.077 |
| 不同风格指令数 / 样本数 | 1 / 18 | 11 / 18 | +10 |

## 结论

- 策略 B 情绪命中率 22.2%（A 为 0.0%），多标签覆盖率 38.9%，说明参数模型能从文本判别情绪而非一律中性；
- 故事场景召回率 100.0%，意图模型未训练时由正则兜底，场景先验得以下发；
- 人设语气注入率 100.0%、共情规则命中率 33.3%，证明 `persona.json` 的「说话风格.语气 / 情感.共情规则 / 禁止」真实参与了语音输出；
- 语速标准差由 0.000 提升到 0.077、风格指令数由 1 增至 11，语音不再千篇一律；
- 当前 NLP 权重未训练，判别主要靠关键词 + 场景/上下文/人设先验；训练 `emotion_bert.pt` / `nlp_bert.pt` 后，模型那一路会自动提高权重分，指标有望进一步提升。
